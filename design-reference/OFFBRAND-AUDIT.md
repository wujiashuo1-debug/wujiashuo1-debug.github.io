# OFF+BRAND 逐段观察与个人站改造依据

研究日期：2026-09-21。参考：https://www.itsoffbrand.com/ 。桌面观察尺寸 1280 × 720；移动端 390 × 844。通过实际滚动、页面导航、截图及可见 DOM 测量观察，不使用其私有实现代码。

## 先纠正上一版的判断

上一版 DESIGN.md 写了“球始终在右侧，只做轻微退让”，这与参考站不符。作品进入时球会移到左侧，作品中段缩退到卡片后方；作品退出后重新回到中央，随后参与服务内容的空间展开。奖项及页尾并不持续展示球。全站统一的是视觉语言和前后关系，不是一个永远不变的右侧位置。

## 首页完整顺序

以下滚动值是截图采样时的近似位置，不是动画源码中的断点；页面有缓动，不能把瞬时 DOM 坐标当成最终停靠坐标。canvas 有透明边缘，其尺寸不等于可见球直径。

| 阶段 | 实际观察 | 设计作用（分析） | 对个人站的启发 |
| --- | --- | --- | --- |
| 开场，约 0 px | 球在中央，canvas 约 610 px；三行大字分别在左上、右中、左下。文字穿过球面；极细圆环延伸至球外。 | 字与球共用一个构图，而非上方标题、下方插图。 | 身份标题围绕球组织，不另外堆简介和技能标签。 |
| 推近，约 380–900 px | 球由中央放大并向右越界；标题内部字母分散退出。介绍宣言从下方进入，可与右侧近景轻微重叠。 | 旧构图退出的同时给新内容腾位置，推镜有承接对象。 | 介绍的出现、标题退出、球的推近使用同一进度。 |
| 介绍及客户，约 900–1700 px | 大标题之后是窄短文与较长正文两列；客户 Logo 是细线网格，球留在右侧背景。 | 宣言 → 解释 → 信任证据，信息密度渐增。 | 用学校专业、项目方法和已确认结果承接，不能伪造客户墙。 |
| 作品进入，约 1800–2400 px | 两列作品占右侧约三分之二；左列起点低于右列。球从右向左移动，约 2287 px 时已在左侧裁切。 | 视觉重心从球移交到作品；左侧标签与留白成为辅助。 | 重排整个作品区，配合球横向让位，而非只更改球的位置。 |
| 作品中段，约 3000–3700 px | 作品卡片大多为接近方形的真实项目画面，标题及符号压在图内。球缩退，部分阶段完全被卡片遮挡。 | 允许作品成为主角；遮挡提供前后深度。 | 不要求每一秒都看见球。现有概念图不能冒充项目截图；需降低重复、加强项目识别。 |
| 作品退出，约 4300 px | 卡片离开后，球重新完整出现在中央；小型项目画面从下方进入其前景。 | 由具体案例切换到横向能力，镜头重新建立空间。 | 用真实工作步骤与能力模块搭建简洁空间，不堆无关装饰。 |
| 服务展示，约 4700–5300 px | 大小不同的画面及服务文字分布于多个深度；球向左移，前景画面放大/移出。 | 镜头像穿行于能力内容，球、图片、标题有共同运动方向。 | 做一个共享时间轴的能力场景；内容是 Listing 分析、检索、审核、C/Python 与内容实践。 |
| 奖项，约 5700–6200 px | 球退出。左侧小标题/数量，右侧细分隔线列表。 | 密集证据需要安静阅读。 | 让专业背景或成果段有停留，不再给每行加独立弹出。 |
| 品牌宣言，约 6500–7800 px | 大型彩色十字形逐步展开，占满视口；一句宣言持续停留并横向进入完整视野。此时球 canvas 尺寸为 0。 | 品牌符号成为转场载体，呼应 Logo；这不是球被放大后的效果。 | 不照搬其十字符号。个人站用自己的成果和文字收束，避免无意义的长滚动。 |
| 页尾，约 8300 px | 大字联系邀请占左侧，右侧站点、社交及办公室链接；背景只留下极细圆环，无主球。 | 情绪结束后，明确提供行动入口。 | 联系方式必须易读易点，球若露出应退居侧边。 |

## 内页不是同一套模板

- **About**：超大两行身份标题与右侧球相交；左侧四章索引；团队照片占据前景。后续用宣言和不同尺寸的方法卡片切换节奏。
- **Work**：超大错位标题，球从中下方露出，第一排作品在首屏已经覆盖标题和球；并非先展示一整屏简介再开始作品。
- **Services**：两行大标题，下方是可展开的实色服务面板；左侧球被面板遮住。阅读内容有稳定背景。
- **Contact**：两行联系标题，右下大球，表单立即覆盖其前景。主要任务是联系，不用长篇自我介绍阻挡入口。
- **菜单与切页**：右下角小型菜单面板，并非全屏菜单。进入 About 时观察到深色遮罩与中央品牌符号，再出现新页；不能据此宣称原站一定是一个跨路由持久 canvas。

## 材质、字体与运动

1. 原站呈现柔和的粉、暖黄、蓝色体积，局部凹陷/高光随交互改变。外侧细圆环是另一层图形，不能和球面涟漪混为一谈。仅凭截图不能反推出其物理模型。
2. 原站桌面标题的 computed style 为 `Ataero Retina OB Edition`、400 字重，1280 宽时约 91 px。特色主要来自轻字重、大尺度、错位排版与字级退出；不是把字换成更粗更怪就会接近。该字体未取得授权，不复制字体文件。
3. 大幅图片和实色面板可以遮挡球，构成深度。每个组件始终透明会让球变成贴在背景上的墙纸。
4. 出入场之间有相当长的阅读区间。滚动不意味着球必须持续巡游。
5. 本次未测量原站帧率，不用截图流畅感冒充性能数据。部分视频此前报告无法播放；后续观察到缩略画面，但未验证每段视频的完整播放。

## 移动端

390 × 844 下，三行标题集中于上部，球在下方完整出现；进入介绍后，观察到以大段文字及单列正文为主，球不占阅读区域。移动端有独立编排，不能仅把桌面的右侧近景缩小。

## 个人站的新分镜约束

| 内容 | 主角 | 球与内容共同发生的变化 |
| --- | --- | --- |
| 首屏身份 | 姓名/定位与球 | 完整球；三行标题建立空间 |
| 我在做什么 | 中文介绍 | 推向右侧近景；文字在腾出的左侧进入 |
| 精选项目 | 项目画面和结论 | 球转向左侧；两列项目在右侧成为前景，随后球退出阅读区 |
| 能力如何连接 | 四个真实实践模块 | 同一个球回到中央；模块围绕中心展开，解释输入、处理、审核与应用 |
| 红果装备档案 | 已确认盈利与工作方法 | 球让到左侧；右侧实色成果面板稳定阅读 |
| 联系 | 邮箱、电话、邀请 | 降低运动，明确下一步 |

保留一个持续存在的球是用户要求。实现中允许同一个球暂时被遮住、裁切或退场；不在各段创建新球。全部调整必须以排版和阅读任务为依据。实际项目素材尚未提供，继续明确标注项目示意，不拿参考站客户画面装饰个人履历。
